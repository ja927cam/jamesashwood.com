Strata

Self-hosted geospatial workspace · 2026

A self-hosted geospatial workspace for a NAS, home server or VPS. Strata serves OpenStreetMap-based basemaps, lets you add and manage private vector and raster layers, imports GeoJSON, GeoPackage, Shapefile, KML, GPX, GeoTIFF/COG, WMS, WFS, ArcGIS and STAC data, and ingests geotagged photos with EXIF metadata. It can also import satellite embeddings for analysis.

The stack is Docker Compose with PostGIS, FastAPI, Redis/RQ workers, React and MapLibre on the front end, TileServer GL and Caddy. It includes accounts, roles, per-layer permissions, version history, background import jobs and a catalogue of 50+ public map overlays.

  • Docker
  • PostGIS
  • FastAPI
  • React
  • MapLibre
  • Redis
  • Geospatial
